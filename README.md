* Python

* Matplotlib

* Search, Sort and Filter Data
* Create Graphs and Charts

## Step 1

Install libraries:

```bash

```

Place CSV file in project folder.

Example:

```text
Sales Dataset.csv
```

## Step 3

Run Python file:

```bash
python project.py
```
